## 問題回答

### 問題一：為什麼 `"4"` 要先轉成數字，才能用於本題的分攤計算？
因為 `"4"` 是字串（`str`），不能直接拿來和金額做除法運算；必須先用 `int("4")` 轉成整數 `4`，才能正確計算每人分攤費用。

### 問題二：如果先扣折價券，再依剩餘餐費計算服務費，第一組的應付總額會變成多少？為什麼和題目規定的結果不同？
若先扣折價券，餐費會先變成 `1200 - 100 = 1100` 元，再算 10% 服務費為 `1100 × 0.10 = 110` 元，應付總額會變成 `1100 + 110 = 1210` 元。這和題目規定的 `1220` 元不同，因為題目規定服務費必須用原始餐費 `1200` 元計算（`120` 元），先折抵會讓服務費少收 `10` 元。
